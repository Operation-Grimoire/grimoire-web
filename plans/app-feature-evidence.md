The website matrix names `e65522326f7924d40fece5402dcbdc4393bd46c2`, which resolves to **v1.0.1-beta.330**. The homepage's `/releases/latest/download/grimoire.apk` URL advertises the stable channel. Current master evidence alone cannot establish what that downloaded APK does. Before publication, bind each claim to the advertised release and separately record device checks. Hold or qualify any feature found only in a beta; changing the advertised download channel needs a product decision.

## Documentation and homepage grouping

The 119-entry matrix mixes complete workflows, settings, interface details, and duplicate parts of the same action. It can serve as an internal checklist, but it is not a strong homepage structure or a count of independent user capabilities.

Use a short overview organized around reader tasks, with detailed instructions below it:

1. **Find books:** install extensions, search sources, browse lists, choose language filters, use NovelUpdates discovery. Put private repositories and source sign-in in conditional setup guides.
2. **Build a library:** save books, categories, sorting/filtering, updates, history, metadata and covers. Grid columns and six sort fields belong in the detailed library guide.
3. **Read and listen:** reader formatting and navigation, resume progress, device TTS, optional ElevenLabs setup, background controls. Voice preview, notification controls, media buttons and caching support this workflow.
4. **Read offline and use EPUBs:** chapter/image downloads and queue management; separate EPUB import, supported whole-book EPUB sources, and EPUB export as distinct procedures with prerequisites.
5. **Move and manage data:** manual/scheduled backup, merge restore, contents/exclusions, EPUB transfer, storage cleanup. Pair backup promises with what must be moved separately.
6. **Control visibility and settings:** incognito's limited scope, hidden-category unlock, history deletion, image masking, appearance/language, and app updates. Avoid an umbrella privacy promise broader than the verified controls.

Source/mirror/login support belongs to the extension capability, while ElevenLabs belongs to an external provider. Keep these conditions beside the relevant claim, not in a distant disclaimer. The task documentation should distinguish finding an option, setting it up, completing the task, and troubleshooting failure.

## Remaining verification before publishing claims

This investigation did not run the Android app, authenticate a source or private repository, retrieve a paid chapter, call ElevenLabs, restore a real backup, install an update, or verify all 119 matrix entries. It inspected implementation paths and release metadata. A complete publication gate still needs a claim inventory bound to stable/beta release SHAs, source evidence for the remaining entries, and representative device acceptance for the advertised build. A supported code path alone does not prove every third-party source currently works.
