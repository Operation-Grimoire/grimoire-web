# Feature index follow-up

- When animated artwork targets text, observe that heading's geometry as well as the document body. A font swap can change the heading width and text bounds while another column keeps the overall section height fixed.

- Write homepage feature copy for a reader who has never installed the app. Explain connected novel websites and website add-ons before using app vocabulary. Abbreviating internal terms can make labels harder to understand; describe the reader's task and introduce the actual menu terms in the linked guide.

- Test Back after opening a real guide. Native form restoration did not retain the feature query in the exercised browser; storing it in the URL made restoration explicit.
- Check moving artwork against new controls at narrow widths. The existing ghost route crossed the new search label; measured avoidance regions let it fade before overlap without changing its artwork or route.
- For text-enlargement checks, measure all font sizes before applying changes and fully reload between simulations. Changing a parent before measuring a child compounds the enlargement; fragment navigation alone does not clear injected styles.
- Category icons consume space beside headings. Allow long category names to wrap at enlarged text sizes. Confirm stylesheet and font loading before accepting browser layout measurements or screenshots; an unstyled render can give misleading results.
