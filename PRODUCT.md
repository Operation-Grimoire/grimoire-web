# Grimoire web

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Android novel readers come first. Extension authors and app contributors are secondary documentation audiences. Confirmed by the user.

## Product Purpose

Help visitors understand Grimoire, install the Android app, and start reading. Documentation supports installation, source setup, reading, extension development, and contribution.

## Capabilities and Constraints

Grimoire is an open-source Android novel reader for web novels and EPUBs. Content sources are separate Android extension APKs distributed through repository indexes. The website uses an Astro homepage and statically exported Next.js/Fumadocs documentation assembled into one deployment.

## Brand Commitments

Keep the Grimoire name and real app assets. The user rejected the light cobalt concepts. Both homepage and docs must be dark and lean into the ghostly, magical app icon: midnight navy, icy blue spectral light, and the spirit rising from an open book. The icon at webapp/public/icon-512.png is the visual anchor. The redesign should develop that identity rather than replace it with a generic literary theme.

## Evidence on Hand

Real app screenshots in webapp/src/assets/screenshots. Existing docs in docs/content/docs. Official extension repository setup instructions in the neighboring grimoire-extensions checkout. No testimonials or usage statistics supplied.

## Product Principles

- Use direct, factual interface copy. No taglines, slogans, or decorative one-liners.

- Explain the app to first-time readers. On the homepage, call sources connected novel websites and extensions website add-ons. Explain the setup before using internal terms; keep the app's technical labels and old feature names searchable.

- Lead with broad book coverage and a short overview of reading, listening, offline access, and library organization. Put the complete feature matrix deeper on the page.
- Help readers reach their first book.
- Demonstrate the app with real screens.
- Keep installation and source setup understandable.
- Share a coherent identity across the homepage and guides.

- Link to the public code and contribution paths before a distinct, centered final download section.
