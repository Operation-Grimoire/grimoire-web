## Download the APK

Grimoire is distributed as an Android APK from GitHub Releases.

1. On your device, open the [latest release](https://github.com/Operation-Grimoire/grimoire/releases/latest).
2. Download `grimoire.apk`.
3. Open the file and allow installation from your browser if prompted.

:::note
Grimoire isn't on the Play Store. You install it directly, which is why Android
asks you to confirm the source the first time.
:::

## In-app updates

Grimoire updates itself: when a new release is available it can download and
install the new APK from within the app, so you don't have to revisit GitHub.

## Next steps

Once installed, [add a repository](/docs/users/add-repositories) to start pulling
in content sources.
