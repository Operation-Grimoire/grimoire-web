Grimoire discovers content sources as separately installed Android APKs. An extension implements the shared source API; a repository publishes the index that readers use to find it.

If you want to install an extension, start with the [reader's source guide](/docs/users/sources/).

## How extensions work

The app uses Android's package manager and manifest metadata to discover sources. Source implementations use the shared `io.grimoire:extensions-api` contract, so the catalog can grow independently of app releases.

The API is capability-based. A source implements the features its site supports: for example, search, popular novels, chapter lists, EPUBs, or a login flow. The app detects those capabilities instead of expecting every site to behave the same way.

## Publish a repository

A repository exposes an `index.json` that points readers to extension APKs. The official repository publishes its index and packages through GitHub Releases. Use its build and release workflow as the current publishing reference rather than maintaining an independent copy of the format.

Readers can add a repository by index URL. An [add-repository link](/add-repo/) can prefill that URL and its display name in Grimoire.
