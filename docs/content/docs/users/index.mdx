Grimoire reads web novels and EPUBs. Extensions connect it to novel sites.

## First steps

1. [Install Grimoire](/docs/users/install/) on your Android device.
2. Open **Browse**, then open **Extensions** and install a source. The official extension repository is enabled by default.
3. Return to **Browse**, open the source, and choose a novel.
4. Add it to your library or open a chapter to start reading.

You can also import an EPUB into your library without installing a source.
