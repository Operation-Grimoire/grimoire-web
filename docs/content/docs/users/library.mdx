---
title: Your library
description: Save, organize, search, and display your books.
---

Your library contains novels from installed sources and imported EPUBs, along with their reading progress.

## Add and organize novels

Open a novel from a source in **Browse**, then add it to your library from the detail screen. Use categories to group books in a way that makes sense to you.

You can search, filter, and sort the library. Categories also support their own background refresh settings. PIN-locked hidden categories keep selected books out of your ordinary library view.

## Categories [#categories]

Open the Library menu and choose **Manage categories** to create, rename, or reorder categories. Move a saved novel through its category action, or long-press library entries and use **Move** for a selection. Select a category tab to view its books.

Categories can have their own library-update settings. [Hidden categories](/docs/users/privacy/#hidden-categories) require a PIN and separate visibility settings; an ordinary category is not locked.

## Library search [#library-search]

Use the search icon in **Library** and enter a query. Search narrows saved novels rather than contacting source catalogs. Clear or close search to restore the list. If a book remains missing, check the category and active filters before adding another copy.

## Library filters [#library-filters]

Open **Filter & sort**. Filter by source, web novel or EPUB type, and status: ongoing, completed, hiatus, cancelled, or unknown. Other controls narrow the list by unread or downloaded content and personal rating. Filters work together, so a restrictive combination can leave an empty list. Clear the relevant choices to broaden the view. Source-supplied status can be incomplete.

## Library sorting [#library-sorting]

In **Filter & sort**, choose **Last read**, **Title**, **Last updated**, **Unread chapters**, **Total chapters**, or **Your rating**, then choose the direction. Sorting changes the displayed order; it does not change chapter order inside a novel. Personal ratings are separate from a source website's score.

## Grid or list [#library-layout]

Open **Settings → Library → Display** and choose **Grid** or **List**. Return to Library to see the result. This setting is independent of the layout for source catalogs in Browse.

## Grid columns [#library-columns]

In **Settings → Library → Columns**, choose two, three, four, or five columns. This controls the library grid. Use fewer columns when titles or covers are too small; switch to List if you prefer more room for text.

## Cover badges [#cover-badges]

Use **Settings → Library → Cover badges** to control read progress, downloaded-chapter count, locked-chapter count, personal rating, and EPUB badges. The chapter-count setting controls whether locked chapters count toward totals and read percentages. A downloaded badge describes stored chapters, not a guarantee that the entire novel is offline.

## Bulk actions [#bulk-actions]

Long-press a novel in Library, then tap additional novels to select them. Use the selection actions to move, mark read or unread, download, or remove entries. Check the selected count before applying an action. Press Back to leave selection mode. Before removing a large selection, [make a backup](/docs/users/backups/).

## Import an EPUB

Use the EPUB import action in the library and choose a file through Android's file picker. Imported books live alongside your source novels and do not need a source extension.

Keep a copy of the original EPUB somewhere you can recover it.

See [EPUB books](/docs/users/epub/) for importing from other apps and transferring files between devices.

## Reading progress

Grimoire records reading progress and supports library refreshes for new chapters. You can also set a personal rating, adjust a novel's metadata, or replace its cover.

If you move a novel to another source, use [source migration](/docs/users/migration/) to carry over matched chapter progress. Progress for unmatched chapters cannot transfer.

## Back up your library

Grimoire supports manual and scheduled local backups. Make a backup before moving devices, replacing an installation, or making a large library change. Keep a copy outside the device you are backing up.

[Backups](/docs/users/backups/) do not include downloaded chapter files, images, or local EPUB files. Transfer those EPUBs separately. [Download chapters](/docs/users/downloads/) that you want to read without a connection.
