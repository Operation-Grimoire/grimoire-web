---
title: Finding novels
description: Search installed sources, use source catalogs, and filter content languages.
---

Install at least one [source extension](/docs/users/sources/) before searching its catalog. Results require a working source and a connection.

## Global search [#global-search]

Open search from **Browse**, enter a novel title, and submit the query to search installed sources. Use **All**, **Pinned**, or **With results** to change which source results you inspect. Open a result to inspect its source and chapter list before adding it to your library.

A source may return no results because it is unavailable, needs login, uses another title, or does not carry the book. Try alternate titles or a search inside that source. Global search does not search every website or install missing extensions.

## Source search filters [#source-search-filters]

Open an installed source in Browse, then use its search and **Filters** controls. The extension defines the filters, so genre, status, and other options vary. Apply the options for that source and inspect the results. Clear or reset filters when a known title disappears.

## Popular and latest lists [#popular-and-latest]

Open a source to browse the popular or latest lists it provides. Select a novel to open its details. These lists come from the source website; some sources provide only one list or organize discovery differently. Refresh or update the extension if a list stops loading.

## Search result preview [#search-result-preview]

Long-press a novel result to open its quick view. Review the available information before opening the full detail screen or using the offered library action. A preview is not the complete chapter list. Open the novel itself to confirm chapter availability and account requirements.

## Content languages [#content-languages]

Open **Settings → Languages → Source language** to select the default content languages for multi-language sources. Leave all unchecked to show every language. A source's own settings can override these defaults. Extension language filters also help narrow which sources appear in Browse or Extensions.

This filters source content; it does not translate books. [Interface language](/docs/users/appearance/#interface-language) and [speech voices](/docs/users/listening/#language-voices) have separate settings.

If you cannot find a book, broaden filters, try an alternate title, and check the source website. [NovelUpdates](/docs/users/novelupdates/) can help you discover series and then look for them in installed sources.
