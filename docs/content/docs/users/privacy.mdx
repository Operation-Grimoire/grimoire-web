---
title: Hiding & locking
description: Pause history, hide selected categories, and mask inline images.
---

These controls have different scopes. Hidden categories limit visibility in the library; incognito affects history recording; image masking changes what the reader displays.

## Incognito [#incognito]

Open **More** and enable **Incognito**. Reading and browsing history stop recording for this session. Turn it off to resume normal recording. The setting is session-scoped rather than a permanent history preference.

Reading progress and read-state changes still save. Existing history stays until you [delete it](/docs/users/history/#clearing-history). Incognito does not make network requests anonymous, erase website cookies, or encrypt stored books.

## Hidden categories [#hidden-categories]

1. Open **Settings → Library → Hidden categories**.
2. Choose **Set up PIN** and enter and confirm a four-to-eight-digit PIN.
3. Select the categories to hide. The default category cannot be hidden.
4. Return to Library and lock hidden categories when finished.
5. Use the library's unlock action and enter the PIN when you want to view them again.

While unlocked, **Show hidden in “All” tab** controls whether those books also appear in All. Unlock before managing the hidden-category settings. **Remove PIN and unhide all** makes all hidden categories visible after confirmation.

This is not a whole-app lock or encrypted file storage. Retain your PIN; this guide does not promise a forgotten-PIN recovery path. Backup files exclude PIN data and biometric settings, so check visibility and set up locks again after restore.

## Device authentication [#biometric-unlock]

In Hidden categories settings, enable **Use biometric unlock** if your device offers it. Enroll a supported fingerprint or face method in Android first. Unlock uses Android's supported authentication dialog and can offer a device-credential fallback. Keep the category PIN available. Device support and enrollment determine which methods appear.

## Image masking [#image-masking]

Enable **Settings → Reader → Hide images**, or change the image setting in the reader. Inline images are hidden until you tap to reveal or hold to peek. Chapter controls can reveal or hide all images in that chapter.

Masking affects display; it does not remove stored images or conceal requests from the source. Check the setting before opening content in a shared space. It is separate from hiding a novel's library category.
