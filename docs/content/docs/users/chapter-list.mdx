---
title: Working with chapters
description: Search, sort, jump, and select chapters on a novel's detail screen.
---

Open a novel's details and let its chapter list load. Source novels need the extension and a connection for a fresh list. Imported EPUB chapters come from the book file.

## Searching and sorting [#searching-and-sorting]

Use chapter search to narrow the list by chapter name. Use the sort control to change chapter order. Clear search to return to the complete list. A filtered view can hide chapters that still exist in the novel; it does not remove them or alter their read state.

If the source returns an incomplete list, check [Update warnings](/docs/users/library-updates/#failed-updates) before changing progress or deleting chapters.

## Jumping to a chapter [#jumping-to-a-chapter]

Tap the chapter-count control above the list to open **Jump to chapter**. Enter a **Chapter number** and choose **Go**, or choose the offered **Next unread** shortcut. This moves you within the displayed list so you can select a chapter. Grimoire looks for the number in chapter metadata or the chapter title. Clear chapter search first if it hides the chapter you want.

## Selecting chapter ranges [#selecting-chapter-ranges]

Long-press a chapter to enter selection mode. Tap more chapters to add or remove them. With one chapter selected, **Select above** and **Select below** extend the selection through the displayed list. Check the active search, sort order, and selected count before using a range action.

Use the selection toolbar to mark chapters read or unread, download them, or manage their downloads. Press Back to leave selection mode. Marking a chapter read changes its state; downloading stores its content. These are separate actions.

For queue controls and offline checks, see [Downloading chapters](/docs/users/downloads/).
