Open **More → Tasks** for running work and completed-task history. Use **More → Downloads** for detailed chapter queue management.

## Background tasks [#background-tasks]

The **Running** area shows active work, including downloads and library syncs. Inspect a task's status before deciding it has completed. Use its cancel action when offered to stop work you no longer want. Cancellation does not imply that completed downloads or earlier library changes have been rolled back.

The **History** area keeps results. A task marked **Finished with errors** needs inspection even if some work succeeded. For failed library updates, open [Update warnings](/docs/users/library-updates/#failed-updates); for failed downloads, inspect and retry entries in [Downloads](/docs/users/downloads/#retrying-and-removing).

To clear completed records, choose the task-log clear action and confirm. Clearing the task log removes completed download and sync history; running tasks are unaffected. It does not clear your reading history or delete chapter downloads.

## When scheduled work has not run

Check the task's schedule and constraints in **Settings → Library updates** or **Backup & restore**. A Wi-Fi or charging requirement can delay a job. Android also controls when background work runs. Open Grimoire, check storage and connectivity, and inspect the last-result field in the relevant settings before requesting another run.

For a backup, verify that an output file exists. For offline reading, verify completed chapter downloads. A queued or running task alone establishes neither result.
