---
title: EPUB books
description: Import local EPUBs, download supported source EPUBs, and export saved chapters.
---

Local EPUB import, source-delivered EPUB downloads, and EPUB export are separate workflows. Keep original book files somewhere recoverable.

## Importing EPUBs [#importing-epubs]

Open **Library → Import EPUB** and choose an EPUB through Android's file picker. Wait for the import result, then open the new library entry and a chapter. Local books do not need a source extension. If import fails, check the file is a readable EPUB and that there is enough device storage; a renamed file is not necessarily a valid EPUB.

## Opening from other apps [#opening-from-other-apps]

Open an EPUB in an Android file manager or another app that offers an **Open with** action, then choose Grimoire. Android must give Grimoire access to the file. Wait for the import and check Library afterward. If Grimoire is not offered, use the library's Import EPUB action instead.

## EPUB sources [#epub-sources]

Some extensions deliver an entire EPUB rather than a scraped chapter list. Install a supported source, open a novel, and look for **Download EPUB**. Login and account access depend on the source. A source detail screen without chapters may need this download before the reader can open its content.

## Whole-book downloads [#whole-book-downloads]

On a supported source novel, choose **Download EPUB** and wait for the file to download and import. Then open its chapters from the novel detail screen. This is different from the per-chapter download queue and does not grant access to content your source account cannot retrieve. Check the source connection and available storage if the operation fails.

## Exporting EPUBs [#exporting-epubs]

Save the novel in Library and download the chapters you want to include. Open the novel's menu and use its EPUB export action, then choose the destination through Android. Export uses downloaded chapters; it is not a way to acquire all chapters from an inaccessible source. Open the exported file to check its contents before removing the originals.

## Moving EPUBs between devices

Library backups do not contain EPUB files. Transfer and import the EPUB on the receiving device as well as restoring library data. Restore can merge progress with a local book that is already present, but it skips a new local EPUB entry when its file is absent. Keep originals and [check backup exclusions](/docs/users/backups/#included-data) before replacing a device.
