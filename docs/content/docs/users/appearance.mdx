---
title: Appearance & language
description: Change app colors, catalog layout, interface language, and guided tours.
---

Open **More → Settings** for app appearance and language. [Reader-page settings](/docs/users/reading/) and [speech voices](/docs/users/listening/) are configured separately.

## App theme [#app-theme]

Open **Appearance → Theme** and choose **System**, **Light**, or **Dark**. System follows Android's light or dark choice. Check the app after changing the system theme if you want it to switch automatically. This setting does not replace a reader-page theme you chose explicitly.

## Dynamic color [#dynamic-color]

On Android 12 or later, enable **Dynamic Color** in Appearance to use wallpaper-derived colors. Android and the device supply these colors. Manual palette selection is disabled while dynamic color applies; turn it off to choose an app palette.

## Color palettes [#color-palettes]

With Dynamic Color off, choose **Color palette** in Appearance. The supplied choices are Default, Grimoire, Ocean, Sunset, Forest, Rose, and Midnight. Return to Default to restore the standard accent palette. A palette changes app colors rather than book text or source content.

## Browse layout [#browse-layout]

Open **Settings → Browse → Display** and choose Grid or List for source catalogs. Adjust Browse columns for a grid when needed. This is separate from **Settings → Library**, so changing one does not require changing the other.

## Interface language [#interface-language]

Open **Settings → Languages → App language** and select a language, or **System default** to follow Android. The app offers 19 named language choices; translated text and completeness can vary by language. This changes interface labels, not book content, source catalogs, or speech pronunciation. Use [content languages](/docs/users/finding-novels/#content-languages) for source filtering.

## First-launch language [#first-launch-language]

Choose your interface language during initial setup. You can change it later through Languages without reinstalling the app. If you chose a language you cannot read, use the same settings path to return to System default or your preferred language.

## Guided tours [#guided-tours]

Open **More → Tours** to replay the in-app guides. Choose the tour for the area you want to revisit and follow its prompts. Replaying a tour is an explanation of the interface, not a reset of your library or preferences. Use the app's ordinary settings when you want to change a saved choice.
