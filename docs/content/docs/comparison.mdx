<Callout type="info" title="Where they differ">
**LNReader** has AniList, MyAnimeList, Kitsu and MangaUpdates tracking, plus cloud
backup. **Grimoire** has private GitHub repositories, whole-book EPUB sources,
source sign-in, locked-chapter support, NovelUpdates integration, ElevenLabs voices,
image privacy mode and PIN-locked hidden categories.
</Callout>

To suggest another app for this comparison, open an issue with a link to its source.
